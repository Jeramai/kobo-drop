Looking for this Wi-Fi network.

    Set up the Kobo

    Do this once. After that, the Kobo shows every book that you send from a phone or computer on the same Wi-Fi.

    1. On the Kobo, tap More, then Beta features, then Web browser.
    2. Go to
    3. Bookmark the page, so you can open it again with one tap.

    On Android, open the Chrome menu and tap Install app. You can then send a book from any app with Share, then Kobo Drop.

    Send from another network

    On the Kobo page, tap Use a code and type

    Also use the code if the Wi-Fi network number here and on the Kobo page are not the same. A VPN, iCloud Private Relay, or mobile data can cause this.

    Books are converted to KEPUB on this device. The server keeps each book for 24 hours and then deletes it. The limit is 100 MB per book.
